# C5：手写 BM25

目标：实现 [build_bm25 / search_bm25](../level05_bm25.py)。允许现成中文分词器；词频、文档频率、长度归一化和排序必须自己实现，不能调用 rank_bm25、Elasticsearch 或其他检索器。

## 输入与索引

build_bm25 接受非空、ID不重复的 chunks，有限 k1>0，有限 0<=b<=1；非法时 ValueError，且在分词前完成校验。tokenize 对每个正文调用一次，返回 list[str]，单个 token 约定非空；不自行额外 lower 或改写 token。将每篇的 token 序列（保留重复）与 chunks 保存为 tuple 快照。允许某篇或全部分词结果为空。

## 本题固定的评分定义

- N：索引中 chunk 数；df(t)：包含词 t 的 chunk 数，每篇最多计一次。
- f(t,d)：词在当前 chunk 中的次数；dl：当前 chunk token 数；avgdl：**全部 N 篇**的平均 token 数，包含空篇。
- `idf(t) = ln(1 + (N-df(t)+0.5)/(df(t)+0.5))`。
- 每个不同查询词的贡献为 `idf(t) * f(t,d)*(k1+1)/(f(t,d)+k1*(1-b+b*dl/avgdl))`，总分为这些贡献之和；查询重复词只算一次，没有命中贡献0。
- avgdl=0 时所有分数0，避免除零。不同系统的 BM25 公式常数可能不同，本题以以上定义为准，不要求与某个服务的原始分数逐项一致。

这是评分契约，不提供遍历／索引构建实现。分词器输出需保持建库与查询一致；中文测试可直接注入预设分词结果，不需要下载模型。

search_bm25 对 question.strip() 校验非空、k>0，在分词前完成；query 分词一次。仅返回分数>0的 SearchHit，降序，同分按原语料顺序，最多k。空 query token 或全无匹配返回 []。依赖异常传播，不修改输入。
