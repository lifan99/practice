# 按需补学的基础

本目录保存短单元的学习目标与独立任务规格，不附作业实现，也没有作业自动测试。配套[基础读物](../readings/README.md)已提供契约、异步、HTTP和服务边界讲解及[七个离线示例](../../support/mvp_examples/README.md)；SQL／容器与模型原理的系统讲义仍待补建。先阅读所需主题，再检查能否独立完成任务；已能给出证据的部分可跳过。代码、标识符和注释用英文，说明可用中文。

| 单元 | 进入时机 | 需要交出的证据 |
| --- | --- | --- |
| [F1 契约、类型与测试](01_contracts.md) | RAG C1 前或读不懂练习契约时 | 明确输入／失败行为、参数化反例、输入保护与依赖隔离 |
| [F2 异步与资源生命周期](02_async.md) | LangChain L9、MCP 或服务并发前 | 调度解释、可控并发探针、取消与释放记录 |
| [F3 HTTP、SQL 与持久化](03_service.md) | 项目 P2 前 | 接口契约、约束与事务测试、真实进程重启测试 |
| [F4 模型调用与评估边界](04_models.md) | P1 首次接模型前 | 版本与调用预算、完整上下文计量、错误与质量分离 |

学完后返回 [主线](../README.md)，不要为完成补学目录推迟第一版项目。F2、F3 可以先做小练习，再把同一能力迁移到项目。
